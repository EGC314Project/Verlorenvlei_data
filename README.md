# Verlorenvlei_data
Verlorenvlei data analysis for the EGC314Project
1. The data presented in this repository was analysed by the code included thereof.
2. Codes are referenced in the final draft and can be used as reference or as supporting evidence.
3. All the presented data was extracted from Dataset_Verlorenvlei_Neat provided in this project.
4. The data included in this repository were manually cleaned on excel.
5. NaN was used to replace missing data values including (/, n.d, and empty tabs).
6. Where the data has approximate values the nearest high was used (i.e, where the data value is approximately 3, it was assumed to be exatly 3 for simplicity).
7. Values showing (<) were replaced by the qouted values (i.e, <0.10 was replaced with 0.10).
